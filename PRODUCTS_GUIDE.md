# Управление каталогом продукции FGN

Каталог устроен так, чтобы часто меняемые данные не искать по HTML-файлам.

## Главный файл

`data/products.json` — единый оперативный источник данных товара. `shop.js` использует его на главной, в каталоге и на странице товара. Статический HTML остаётся резервом для SEO и случая, когда JSON временно не загрузился; его соответствие JSON контролирует автоматическая проверка.

В нём можно менять:

- ссылку на Ozon: `ozon.url`;
- доступность кнопки Ozon: `ozon.active`;
- порядок на главной и в каталоге: `catalogOrder`;
- название и три характеристики карточки: `catalog`;
- видимость товара на главной и в каталоге: `active`;
- номер и дату СГР или других документов: `documents`;
- изображения каталога и карточки: `images`.
- статические SEO-поля карточки: `seo`.

Цена на сайте специально не хранится. Актуальная цена и наличие показываются только на Ozon.

## Если ссылка Ozon изменилась

Поменять только значение:

```json
"ozon": {
  "active": true,
  "url": "https://www.ozon.ru/product/.../"
}
```

HTML карточки править не требуется: `shop.js` подставит новую ссылку во все кнопки товара. После изменения выполнить `node scripts/check-repository.mjs`.

## Если товар временно снят с продажи на Ozon

```json
"ozon": {
  "active": false,
  "url": ""
}
```

Кнопка покупки скроется.

## Если у товара нет СГР для показа

Использовать пустой список:

```json
"documents": []
```

Блок «Документы» в карточке автоматически скроется.

Для нескольких документов:

```json
"documents": [
  {
    "type": "СГР",
    "active": true,
    "number": "НОМЕР",
    "date": "ДД.ММ.ГГГГ"
  }
]
```

## Если товар надо полностью скрыть из каталога

```json
"active": false
```

Данные останутся в файле, но карточка будет скрыта и на главной, и в каталоге. Страница товара сохранится как HTML-резерв, поэтому при окончательном снятии продукта нужно отдельно решить, оставлять ли её индексируемой.

## Порядок и карточка каталога

```json
"catalogOrder": 1,
"catalog": {
  "name": "Хмель",
  "package": "60 капсул",
  "capsule": "320 мг",
  "composition": "Экстракт шишек хмеля"
}
```

`catalogOrder` должен быть уникальным. Значения `catalog` автоматически обновляют главную карусель и каталог. При добавлении нового товара нужно также создать статические HTML-карточки на главной и в каталоге: проверка требует полного совпадения резерва с активными товарами.

## Изображения

Хранить в:

`assets/products/<slug>/`

Для каждого товара используются:

- `bottle-catalog.webp` — облегчённое превью каталога;
- `bottle-cutout.png` — банка на прозрачном фоне;
- `hero.png`, `benefits.png`, `composition.png`, `usage.png`, `formula.png` — мастер-файлы;
- одноимённые файлы `.webp` — облегчённые версии, которые подключаются на сайте.

Массив `images.gallery` управляет путями изображений существующей галереи. Количество изображений в JSON и HTML-резерве должно совпадать; это проверяется автоматически.

## SEO-контракт карточки

Объект `seo` хранит точные значения `title`, meta description, Open Graph, имени и описания Product JSON-LD, списка Schema-изображений и названия товара в BreadcrumbList. `images.hero` задаёт изображение для Open Graph и основное изображение Product Schema.

При изменении названия, количества капсул, массы капсулы или изображения нужно одновременно обновить связанные поля `seo` и статический `<head>` страницы. Валидатор сравнивает их точно и дополнительно требует актуальные `catalog.package` и `catalog.capsule` в SEO-описаниях. Несогласованная карточка не пройдёт pull request.

## Юридическая проверка перед добавлением продукта

До публикации каждого продукта сверить с действующими документами:

1. точное наименование;
2. область применения;
3. состав;
4. рекомендации по применению;
5. противопоказания;
6. срок и условия хранения;
7. категорию продукта и основание для неё;
8. номер и статус СГР, если он выводится;
9. текст на готовых рекламных изображениях.

Не переносить на сайт неподтверждённые обещания лечебного эффекта. Для ежовика используется предупреждение «БАД. Не является лекарственным средством.». Для остальных товаров — «Пищевая добавка. Не является лекарственным средством.».

## Проверка перед публикацией

```bash
node scripts/check-repository.mjs
node scripts/browser-smoke.mjs
git diff --check
```

Проверки контролируют JSON, 11 страниц, изображения, галереи, Ozon-ссылки, категории, HTML-резерв, локальные ссылки, все SEO-поля карточек, JSON-LD, sitemap, версии общего CSS, inline-стили, типовые признаки случайно добавленных секретов и поведение сайта в Chromium на основных мобильных ширинах.
