# Управление каталогом продукции FGN

Каталог устроен так, чтобы часто меняемые данные не искать по HTML-файлам.

## Главный файл

`data/products.json` — единый файл для оперативных изменений товара.

В нём можно менять:

- ссылку на Ozon: `ozon.url`;
- доступность кнопки Ozon: `ozon.active`;
- видимость товара в каталоге: `active`;
- номер и дату СГР или других документов: `documents`;
- изображения каталога и карточки: `images`.

Цена на сайте специально не хранится. Актуальная цена и наличие показываются только на Ozon.

## Если ссылка Ozon изменилась

Поменять только значение:

```json
"ozon": {
  "active": true,
  "url": "https://www.ozon.ru/product/.../"
}
```

HTML карточки править не требуется: `shop.js` подставит новую ссылку во все кнопки товара.

## Если товар временно снят с продажи на Ozon

```json
"ozon": {
  "active": false,
  "url": ""
}
```

Кнопка покупки скроется.

## Если у товара нет СГР для показа

Использовать пустой список:

```json
"documents": []
```

Блок «Документы» в карточке автоматически скроется.

Для нескольких документов:

```json
"documents": [
  {
    "type": "СГР",
    "active": true,
    "number": "НОМЕР",
    "date": "ДД.ММ.ГГГГ"
  }
]
```

## Если товар надо полностью скрыть из каталога

```json
"active": false
```

Данные останутся в файле, но карточка не будет выводиться в каталоге.

## Изображения

Хранить в:

`assets/products/<slug>/`

Для ежовика сейчас используются:

- `assets/products/ezhovik/catalog.webp` — превью каталога;
- `assets/products/ezhovik/01-main.webp` — основное изображение;
- `assets/products/ezhovik/02-benefits.webp` — дополнительная инфографика;
- `assets/products/ezhovik/03-composition.webp` — состав и характеристики;
- `assets/products/ezhovik/04-for-whom.webp` — дополнительная инфографика.

## Юридическая проверка перед добавлением продукта

До публикации каждого БАД сверить с действующими документами:

1. точное наименование;
2. область применения;
3. состав;
4. рекомендации по применению;
5. противопоказания;
6. срок и условия хранения;
7. номер и статус СГР, если он выводится;
8. текст на готовых рекламных изображениях.

Не переносить на сайт неподтверждённые обещания лечебного эффекта. Предупреждение «БАД. Не является лекарственным средством.» должно оставаться заметным.
