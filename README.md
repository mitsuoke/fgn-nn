# FGN — Forrest Gamp Nutrition

Официальный сайт направления контрактного производства БАД и фасовки ООО «Бурундук Шоп».

**Публичный адрес:** https://mitsuoke.github.io/fgn-nn/

## Позиционирование

FGN — сильное собственное производство, с которым просто работать. Компания помогает заказчику на любом этапе: от идеи и подбора сырья до упаковки, маркировки и выпуска готовой партии.

Основные принципы коммуникации сайта:

- честно оценивать возможности, сроки и риски;
- объяснять производственные вопросы простым языком;
- подтверждать компетентность фактами, а не рекламными обещаниями;
- показывать реальное производство и реальные продукты;
- помогать заказчику с рецептурой, сырьём, упаковкой и маркировкой.

## Подтверждённые факты

- производство работает с 2023 года;
- произведено более 1 000 000 банок;
- минимальная партия капсул — от 100 банок;
- мощность — до 5 000 банок по 60 капсул за смену;
- фасовка сухой продукции — до 15 000 пакетов в сутки;
- возможно увеличение загрузки до трёх смен;
- производственная площадка находится в г. Павлово Нижегородской области;
- действует собственное СГР на БАД с ежовиком гребенчатым.
- система менеджмента безопасности пищевой продукции сертифицирована в добровольной системе на соответствие ISO 22000:2018 и ISO/TS 22002-1:2009; сертификат № 12AP64-1 действует с 19.05.2026 по 18.05.2029.

## Целевая аудитория

Сайт рассчитан на четыре группы заказчиков:

1. новый бренд, у которого пока есть только идея;
2. продавец, готовящий продукт к маркетплейсам;
3. действующий бренд БАД, которому нужен новый продукт или масштабирование;
4. заказчик, которому требуется только фасовка или отдельная операция.

## Структура проекта

- `index.html` — главная страница;
- `styles.css` — фирменный дизайн и адаптивная вёрстка;
- `script.js` — мобильное меню, анимация появления и форма заявки;
- `privacy.html` — политика обработки персональных данных;
- `assets/` — оптимизированные фотографии производства, продукции и превью СГР.
- `assets/iso-22000-preview.webp` — защищённое веб-превью добровольного сертификата ISO 22000.

## Публикация

GitHub Pages публикует содержимое ветки `main` из корня репозитория. После обновления файлов CDN GitHub может показывать предыдущую версию несколько минут. При изменении CSS или JavaScript необходимо увеличивать номер версии в `index.html`, например `styles.css?v=4`, чтобы браузеры не использовали старый кэш.

## Форма заявки
