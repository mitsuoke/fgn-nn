# FGN — сайт контрактного производства

Первая версия статического сайта, подготовленная для GitHub Pages.

## Состав

- `index.html` — главная страница;
- `styles.css` — весь дизайн и мобильная адаптация;
- `script.js` — меню и форма предварительного расчёта;
- `privacy.html` — черновик политики обработки персональных данных.

## Публикация на GitHub Pages

1. Создать новый репозиторий на GitHub.
2. Загрузить в корень репозитория все файлы из этой папки.
3. Открыть `Settings → Pages`.
4. В разделе `Build and deployment` выбрать `Deploy from a branch`.
5. Выбрать ветку `main` и папку `/root`, затем сохранить.

## Что заменить после получения материалов

- временный текстовый знак `FGN` на официальный логотип;
- четыре фотозаглушки на фотографии производства;
- три карточки кейсов на реальные продукты;
- контактную почту на адрес на домене компании;
- черновые реквизиты и политику обработки данных;
- демонстрационную отправку через email на нормальную форму или CRM;
- подтвердить все производственные показатели перед публикацией.

## Важно

Сейчас форма формирует письмо в почтовой программе посетителя. Для производственной версии рекомендуется подключить собственный обработчик формы, CRM или сервис приёма заявок.
